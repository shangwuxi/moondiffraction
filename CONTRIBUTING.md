# Contributing and scope

Run `moon fmt --check`, target check/build/test, all three cmd examples and `python scripts/oracle.py`. Add regression tests for numeric or budget changes. Explain any change to units, sign convention, completeness, centering expansion, grouping or area semantics. Do not extend into CIF parsing or general crystal chemistry without a fresh project-boundary review.

Do not commit credentials, private datasets, application contacts, toolchains or build outputs. Use repository-local identity; never change global Git/GitHub account settings for this project. Before pushing, verify owner and active account. This entry's current contributor is shangwuxi; source attribution must remain accurate if future contributions arrive.
